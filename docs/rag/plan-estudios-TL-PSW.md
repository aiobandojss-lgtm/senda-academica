# Plan de estudios – Técnico Laboral en Programación de Software

> Documento FICTICIO de demostración. Se reemplaza por el plan de estudios oficial.

## Perfil del egresado

El egresado puede construir programas sencillos, diseñar y consultar bases de datos relacionales y desarrollar páginas web responsivas, como programador junior o auxiliar de desarrollo.

## Duración

Tres semestres de 16 semanas, con práctica empresarial en el tercer semestre.

## Semestre 1

- Lógica de programación: algoritmos, condicionales, ciclos, funciones y arreglos.
- Bases de datos: modelo entidad-relación, SQL básico y normalización.
- Desarrollo web básico: HTML, CSS y JavaScript.

## Semestre 2

- Programación orientada a objetos.
- Desarrollo de aplicaciones web con un framework.
- Control de versiones con Git.

## Semestre 3

- Proyecto integrador.
- Práctica empresarial de 440 horas.

## Requisitos de grado

Aprobar todos los cursos con nota mínima de 3.0, completar la práctica empresarial y estar a paz y salvo con la Fundación.
