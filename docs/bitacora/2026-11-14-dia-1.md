## Conceptos aprendidos

- **`engines` en `package.json`:** cada paquete declara qué versiones de Node soporta. Wrangler, OpenSpec 2 y vitest exigen Node ≥ 22.12; con Node 20 fallan. fnm permite tener varias versiones y cambiar según el `.node-version` de cada carpeta, y los paquetes globales quedan separados por versión.
- **`.gitattributes` frente a `core.autocrlf`:** `autocrlf` depende de la configuración de cada máquina; `.gitattributes` viaja con el repo y se aplica igual en Windows y en el CI de Linux. Los binarios se marcan para que Git nunca les cambie los saltos de línea.
- **Primer commit intacto:** permite mostrar con `git diff` exactamente qué se cambió del diseño original y por qué.
- **OpenSpec 2:** las skills quedan en `.agents/skills/` (convención compartida por varios agentes, incluido Antigravity) con enlaces desde `.claude/skills/`; los comandos `/opsx:*` del curso pasan a ser `/openspec-*`.
- **Spec primero, también para mejorar:** las mejoras se escribieron en los specs (requisito + escenarios WHEN/THEN), luego en el diseño (decisión + alternativa descartada) y en las tareas (con su verificación), antes de cualquier código.
- **Defensa en profundidad con triggers:** las reglas de dinero y notas se validan en la API **y** en la base (`RAISE(ABORT, 'CODIGO')`), como en Oracle con `RAISE_APPLICATION_ERROR`. Una migración solo se puede editar mientras no se haya aplicado en ninguna base.
- **Calcular en vez de guardar:** la mora y la marca de entrega tardía se calculan al vuelo para que nunca queden desactualizadas.
- **Sesiones JWT revocables:** un JWT puro no se puede invalidar antes de que venza; con `sesion_version` en la base, restablecer la contraseña o desactivar a un usuario cierra sus sesiones al instante.

## Problemas y cómo se resolvieron

| Problema | Causa | Solución |
|---|---|---|
| Wrangler, OpenSpec 2 y vitest no corrían | Node 20 en el PATH del sistema | fnm con Node 24 y `fnm env --use-on-cd` en el perfil de PowerShell |
| Git advertía que convertiría `placeholder.pdf` | `core.autocrlf=true` trataba el PDF como texto y lo habría corrompido | `.gitattributes` con `*.pdf binary` |
| La propuesta prometía recuperación por correo y el diseño no | Alcance comercial y técnico desalineados | Se mantiene el restablecimiento por el administrador; el correo pasa a una fase posterior |
| El plan Free de Workers da 10 ms de CPU por petición | PBKDF2 con 100.000 iteraciones podría superarlo | Tarea 1.8 para medirlo con el Worker desplegado |
